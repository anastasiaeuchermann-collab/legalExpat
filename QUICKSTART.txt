📦 STEP 1: INSTALL DEPENDENCIES
────────────────────────────────────────────────────────────────────────

Open your terminal in this directory and run:

    npm install

This will install all required packages (~2-3 minutes).


🔧 STEP 2: CREATE ENVIRONMENT FILE
────────────────────────────────────────────────────────────────────────

Create a file named .env.local in this directory:

    # macOS/Linux:
    touch .env.local

    # Windows PowerShell:
    New-Item .env.local

Copy this into .env.local:

────────────────────────────────────────────────────────────────────────
# Supabase Configuration
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-key-here
SUPABASE_SERVICE_ROLE_KEY=your-service-role-key-here

# NextAuth Configuration
NEXTAUTH_URL=http://localhost:3000
NEXTAUTH_SECRET=your-random-secret-min-32-characters

# Google OAuth (Optional - for "Sign in with Google")
GOOGLE_CLIENT_ID=your-google-client-id
GOOGLE_CLIENT_SECRET=your-google-client-secret
────────────────────────────────────────────────────────────────────────

WHERE TO GET THESE:

1. Supabase Keys:
   • Go to https://app.supabase.com/
   • Create new project or select existing
   • Go to Settings → API
   • Copy the keys as shown above

2. NextAuth Secret:
   • Generate random string:
     macOS/Linux: openssl rand -base64 32
     Online: https://generate-secret.vercel.app/32

3. Google OAuth (Optional):
   • Only needed if you want "Sign in with Google"
   • Can skip for now and add later


💾 STEP 3: SET UP DATABASE
────────────────────────────────────────────────────────────────────────

In your Supabase project:

1. Click "SQL Editor" in left sidebar
2. Click "New Query"
3. Open this file: supabase/migrations/20240101000001_create_users_and_profiles.sql
4. Copy and paste into SQL Editor
5. Click "Run"
6. Repeat for ALL files in supabase/migrations/ folder (in order)

Or see SETUP_INSTRUCTIONS.md for automated method.


🚀 STEP 4: START THE APP
────────────────────────────────────────────────────────────────────────

Run this command:

    npm run dev

Open your browser to:

    http://localhost:3000

You should see the LegalExpat homepage!


✅ STEP 5: CREATE TEST ACCOUNTS
────────────────────────────────────────────────────────────────────────

METHOD A - Through Browser (Easiest):

1. Go to http://localhost:3000/register
2. Create an account (Expat or Legal Expert)
3. Skip email verification with this SQL in Supabase:

   UPDATE users
   SET email_verified = true,
       verification_token = null
   WHERE email = 'your-email@test.com';

4. Login at http://localhost:3000/login
5. Complete onboarding

🆘 TROUBLESHOOTING
────────────────────────────────────────────────────────────────────────

Problem: "Port 3000 already in use"
Solution:
  macOS/Linux: lsof -ti:3000 | xargs kill -9
  Windows: Get-Process -Id (Get-NetTCPConnection -LocalPort 3000).OwningProcess | Stop-Process

Problem: "Module not found"
Solution:
  rm -rf node_modules package-lock.json
  npm install

Problem: "Supabase connection error"
Solution:
  • Check .env.local has correct values
  • Verify Supabase project is running
  • Restart dev server after changing .env.local

See SETUP_INSTRUCTIONS.md for more troubleshooting.
